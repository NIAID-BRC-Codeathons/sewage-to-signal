Codeathon project proposal

Benchmarking anomaly detection in wastewater with synthetic spike-ins

Build in silico wastewater samples carrying a known, hidden signal — then use them to measure whether a sparse-autoencoder protein encoding detects that signal where homology search cannot.

01

Project summary

  • Create in silico wastewater samples that model specific environmental noise and pathogen fragmentation, calibrated against real Chicago influent metagenomes. Insert a known signal — pathogen genomes fragmented and mutated to a controlled divergence — at controlled abundance, so detection of that signal can be benchmarked against ground truth.
  • Create an encoding-based anomaly detection pipeline in which each predicted protein is encoded as a sparse fingerprint of interpretable features from an ESMC-6B sparse autoencoder, and an anomaly is a protein whose fingerprint has no near neighbour in a reference index of the ESM Atlas.
  • Release both halves together: the generator and its labelled datasets as a reusable benchmark, and the detector as a modular seven-stage pipeline, so that any future method can be scored on the same footing.
Why a synthetic benchmark is the necessary starting point

We sequenced the problem directly. A k-mer spectrum over a real CASPER wastewater metagenome subsample (302 Mbp, k=21) found 81.5% of distinct k-mers are singletons — the community's novel long tail sits near 1× coverage, precisely the fraction an anomaly detector is meant to surface. Real data therefore cannot tell you whether a miss was the detector's fault or the sequencing depth's. Only a sample with inserted, labelled signal separates those two failure modes.

02

Goals and objectives

Goal 1 · Calibrated synthetic sample generator proposed

Generate labelled in silico wastewater datasets over a grid of fragmentation regimes, error models and spike-in abundances, with per-ORF ground truth. Noise must be realistic, not arbitrary: the generator is calibrated against the measured k-mer spectrum of real CASPER data.

Success: ≥12 datasets (3 fragment-length regimes × 2 error models × ≥3 spike abundances); generated k-mer multiplicity profile within ±5 percentage points of the measured real profile (81.5% singleton / mean multiplicity 6.54).

Goal 2 · Establish a detection limit proposed

Quantify spike-in recovery as a function of relative abundance and fragment length, producing a detection-limit curve rather than a single accuracy number. This is the output a public health lab actually needs when designing sampling depth.

Success: precision/recall and ROC-AUC reported per grid cell; the minimum relative abundance achieving recall ≥ 0.80 is stated with a confidence interval.

Goal 3 · Beat the homology baseline where it matters proposed

Score the SAE encoding against an MMseqs2 / HMMER homology baseline on identical inputs. The claim under test is narrow and falsifiable: the encoding should help specifically on divergent signal, where sequence identity has decayed past homology search's reach.

Success: ≥15 percentage point recall gain over the baseline on the divergent subset (spike-ins mutated to 30–50% identity to any reference), at matched false-positive rate.

Goal 4 · Reference index optional

Encode the ESM Atlas cluster representatives to build a true feature → cluster index, replacing the UniRef-accession bridge the prototype currently depends on.

Current bridge covers 2.3% of feature-table accessions (35,569 / 1,553,786). Target: ≥95% of query features resolve to ≥1 cluster.
03

Approach

Methods

  • Encoder — ESMC-6B with a sparse autoencoder on layer 60 (k=64, codebook 16,384). We use an SAE rather than raw embeddings for one reason: each of the 16,384 features carries a published biological description, so every anomaly call comes with a human-readable rationale instead of a distance.
  • Anomaly score — IDF-weighted similarity between a query's top-K feature fingerprint and its nearest reference cluster. Features are weighted by inverse document frequency in UniRef90, which suppresses features that fire on nearly every protein.
  • Gene calling — pyrodigal in metagenomic mode, handling partial genes at contig edges.
  • Baseline — MMseqs2 and pyhmmer/Pfam, run as a pipeline stage so the comparison is like-for-like.
  • Signal insertion — BV-BRC pathogen genomes fragmented under empirical length and error models, mutated to target identity, then mixed into real wastewater background at set abundance.

Pipeline workflow

  1. Read QC built
    Paired sliding-window trim, mates kept synchronised. Verified: 1,000,000 pairs in, 998,003 kept (99.8%).
  2. Assembly
    MEGAHIT / metaSPAdes. Required — 151 bp reads translate to 50 aa, too short to contain a domain, and one indel garbles the frame.
  3. Gene calling built
    pyrodigal. Validated against SARS-CoV-2 NC_045512.2: recovers Spike at 21563–25384 (1273 aa), matching the canonical annotation exactly.
  4. Dereplication built
    Hash dedup plus MMseqs2 linclust. Surveillance resequences one sewershed repeatedly, so redundancy here is the cheapest large saving in the pipeline.
  5. Homology prefilter built
    pyhmmer or pyswrd. The main cost lever: proteins with a confident family hit are already annotated and never reach the GPU.
  6. SAE encoding built
    Length-bucketed batching; top-K taken directly off the sparse tensor, so memory is flat in sequence length. Emits long-format parquet.
  7. Match & annotate built
    Feature descriptions joined, candidate clusters ranked by fingerprint voting.

Why the funnel shape, in numbers

Raw CASPER reads 4.0 × 10¹¹
Assembled ORFs ~10⁹
After dereplication ~10⁷–10⁸
After prefilter → GPU ~10⁶–10⁷

Bars are log-scaled; values as labelled. Embedding reads directly is not a slow option but an impossible one — at the measured best rate of 0.107 M sequences/day, 4.0 × 10¹¹ reads would take on the order of 10,000 years. The prefilter, not the GPU, is what makes the problem tractable.

05

Expected outcomes and deliverables

Benchmark suite proposed

Labelled in silico wastewater datasets with per-ORF ground truth, plus the generator that made them, so results are reproducible and the grid extensible.

Detection-limit report proposed

ROC curves and recall-versus-abundance curves for the SAE encoding and the homology baseline, with the divergence sweep that separates them.

Working pipeline built

Seven modular stages, resumable, each writing a provenance manifest. Entry at reads, contigs or proteins. Already validated end to end.

Interpretable call sheets proposed

Every flagged protein accompanied by the named features that fired and the clusters they nominate — evidence an analyst can audit.

Reference index optional

Feature → cluster index over the atlas representatives, reusable by any downstream project and not specific to this one.

BV-BRC integration concept proposed

A sketch for exposing SAE fingerprints as a BV-BRC protein annotation track, and the benchmark as a shared evaluation target.

Proof the interpretation layer works

Given only the 29,903 nt SARS-CoV-2 genome — no annotation, and no indication it was a coronavirus — the pipeline called genes itself and returned, for the Spike gene, features described as entry/fusion envelope ectodomains, viral envelope/spike/fusion proteins, viral envelope/fusion glycoproteins and fusion peptides, membrane-proximal/TM anchors. Five independent features, each correct for a protein with a signal peptide, an ectodomain, a fusion peptide and a TM anchor.

06

Potential impact and next steps

Infectious disease research

Wastewater surveillance currently sees what it already has references for. A protein-encoding detector targets the opposite case — agents divergent enough that homology search returns nothing — and the benchmark states honestly how divergent a thing can be before detection fails. That boundary is the useful deliverable, whichever side of it the method lands on.

AI/ML automation and interpretability

Anomaly detection on embeddings usually returns a distance and no reason. Sparse autoencoder features return named biological concepts, which makes a flag auditable by a domain expert rather than merely trusted. The benchmark also supplies something the interpretability field is short of: a task with ground truth, where a feature-based explanation can be scored rather than admired.

Public health preparedness and education

Detection-limit curves convert directly into sampling guidance — how deep a run must be to catch an agent at a given abundance. The synthetic datasets double as teaching material, since the answer is known and students can see a detector succeed and fail under controlled conditions.

Follow-up after the Codeathon

  • Scale from the 302 Mbp subsample to full CASPER runs, where the rare fraction is actually assemblable.
  • Add an rRNA depletion stage — untargeted wastewater RNA-seq is rRNA-dominated and would otherwise spend GPU time on spurious ORFs.
  • Run prospectively across the Chicago site time series, including the S0120 sewershed that spans the 2026 lab handover.
  • Publish the benchmark as a standing evaluation target and the index as a community resource.
